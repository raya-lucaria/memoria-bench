01 / DEFINITIONWhat is a harness?

The working definition from the primary sources: Agent = Model + Harness. The harness is every piece of code, configuration and execution logic that is not the model itself. DOCUMENTED LangChain's "Anatomy of an Agent Harness" (Mar 2026) is where this formula is stated directly. Anthropic uses "harness" (and "scaffold" as a synonym) for the same thing.

Click a layer to see what it does and where each studied harness puts it.

Two meanings that get mixed up

Agent harness

The runtime wrapped around the model while it acts: loop, tools, context, permissions, state. Claude Code, pi, Hermes Agent and SWE-agent are this kind. Evaluating an agent evaluates model and harness together (Anthropic, "Demystifying evals").

Evaluation harness

Test infrastructure that runs a model or agent against a benchmark and scores it: EleutherAI's lm-evaluation-harness, the SWE-bench grader, UK AISI's Inspect (which calls itself a framework). Older meaning, different thing.

Where sources disagree
Nobody owns the term. The earliest dated use of "harness engineering" that the research found is Mitchell Hashimoto's blog post of 5 Feb 2026; Anthropic was already calling the Agent SDK a "harness" in Nov 2025. LangChain nests context engineering inside the harness; a summary of OpenAI's post (which the research could not fetch, 403) frames harness engineering as broader. Frameworks (LangChain, CrewAI) are libraries you build with; a harness is a runtime you work inside, but Anthropic's own SDK blurs that line. DOCUMENTED
Marketing vs evidence
Weak, widely repeated: LangChain's "Top 30 to Top 5" Terminal Bench claim comes with no scores in the post, and figures like "88% of agent projects fail because of the harness" appear only on unsourced SEO pages. Strongest: Anthropic's March 2026 post reports real costs (a solo run $9 / 20 min vs a full harness $200 / ~6 h), though it is a single-vendor case study. Vendors sell what they describe.
