# AGENTS.md

## Proyecto
Juego para aprender cualquier tema mientras te diviertes.

## Comandos
- Tests: `pytest -q`
- Lint: `ruff check .`

## Mapa
- `src/colas/` — lógica del simulador (sin I/O)
- `tests/` — un archivo de test por módulo

## Reglas
- No modifiques `tests/fixtures/`: son datos externos.
- Usa `random.Random(seed)`, nunca el `random` global.
