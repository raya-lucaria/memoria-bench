# AGENTS.md

## Proyecto
Juego para aprender cualquier tema mientras te diviertes.

## Comandos
- Tests: `pytest -q`
- Lint: `ruff check .`

## Mapa
- `specs/` — propuestas de diseño (fuente de verdad del producto)
- `memoria-versionada/` — memoria del agente (ver «Memoria»)
- Verifica una ruta con `ls` antes de confiar en este mapa.

## Reglas
- No modifiques `tests/fixtures/`: son datos externos.
- Usa `random.Random(seed)`, nunca el `random` global.
- Antes de terminar, corre tests y lint y reporta el resultado.

## Memoria
- Lee `memoria-versionada/memoria/INDICE.md` al empezar.
- Propón, no apruebes: `python3 memoria-versionada/mem.py proponer ...`.
